### 2.2. Реалізація MainActivity

**Основний функціонал:**

```kotlin
@Composable
fun HelloComposeApp() {
    MaterialTheme {
        var name by remember { mutableStateOf("Студент") }

        Surface {
            Column(modifier = Modifier.padding(16.dp)) {
                Text(
                    text = "Привіт, $name!",
                    style = MaterialTheme.typography.headlineMedium
                )
                Button(onClick = { name = "Світ" }) {
                    Text("Натисни")
                }
            }
        }
    }
}
```

**Особливості реалізації:**
- ✅ Використання Jetpack Compose для UI
- ✅ Material Design 3
- ✅ State management через `remember` і `mutableStateOf`
- ✅ Інтерактивність через Button
- ✅ Українська локалізація
- ✅ Preview для швидкої розробки

## 8. GitFlow Workflow

### Робота з feature:
```bash
# Створення нової фічі
git checkout develop
git checkout -b feature/new-feature

# Робота над фічею
git add .
git commit -m "Add new feature"

# Злиття в develop
git checkout develop
git merge feature/new-feature
git push origin develop
```

### Підготовка релізу:
```bash
# Створення release branch
git checkout develop
git checkout -b release/v1.0.0

# Фінальні зміни та тестування
git commit -m "Prepare release v1.0.0"

# Злиття в main та develop
git checkout main
git merge release/v1.0.0
git tag v1.0.0
git push origin main --tags

git checkout develop
git merge release/v1.0.0
git push origin develop
```
