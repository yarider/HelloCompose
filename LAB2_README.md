# LabScreensApp - Лабораторна робота №2

Додаток для демонстрації роботи зі списками, деталями, AppBar та темізацією в Jetpack Compose.

## Функціонал

### ✨ Основні можливості
- 📋 **Список елементів** - LazyColumn з 20 елементами
- 🎨 **Іконки** - Унікальні іконки для кожного типу елементів
- 🔍 **Пошук** - Фільтрація елементів по назві та опису
- 📱 **Деталі** - Детальна інформація про кожен елемент
- 🔄 **Поділитися** - Можливість поділитися інформацією
- 🌓 **Темна тема** - Автоматичне перемикання світлої/темної теми
- 🧭 **Навігація** - Плавна навігація між екранами

### 🎯 Виконані завдання
1. ✅ Іконки для кожного елемента списку
2. ✅ Реалізована темна тема (darkColorScheme)
3. ✅ Кнопка меню в AppBar
4. ✅ Кнопка "Поділитися" на екрані деталей
5. ✅ Пошук по списку (додаткове завдання)

## Архітектура проєкту

```
com.example.hellocompose/
│

│
├── model/
│   └── Item.kt                 # Модель даних
│
├── screens/
│   ├── ItemListScreen.kt      # Екран списку
│   └── ItemDetailsScreen.kt   # Екран деталей
│
├── navigation/
│   └── AppNavigation.kt       # Навігаційний граф
│
└── ui/theme/

    └── Type.kt               # Типографія
```

## Технології

- **Kotlin** - Мова програмування
- **Jetpack Compose** - Сучасний UI toolkit
- **Material 3** - Дизайн-система Google
- **Navigation Compose** - Навігація між екранами
- **LazyColumn** - Оптимізовані списки
- **State Management** - Управління станом

## Компоненти Material 3

### Використані компоненти:
- `CenterAlignedTopAppBar` - Верхня панель з центрованим заголовком
- `TopAppBar` - Звичайна верхня панель
- `LazyColumn` - Список з ледивим завантаженням
- `ListItem` - Елемент списку
- `Card` - Картка для групування контенту
- `TextField` - Поле введення для пошуку
- `Button` - Кнопки дій
- `Icon` & `IconButton` - Іконки та іконкові кнопки
- `Scaffold` - Базова структура екрану
- `HorizontalDivider` - Роздільник між елементами

## Як запустити

1. Відкрийте проєкт в Android Studio
2. Синхронізуйте Gradle файли
3. Запустіть на емуляторі або реальному пристрої (Android 8.0+)

- Android SDK 26+
